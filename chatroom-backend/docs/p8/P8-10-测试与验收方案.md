## 2.1 攻击用例专项（P8-05 §4 全量，报告口径固定）

| 用例 | p4_demo 模式预期 | multi 模式预期 | 允许标记 |
|---|---|---|---|
| ATK-1/2（改 user_id 越权） | 白名单拒绝 → **PASS** | 未绑定则 **REPRO** | 按模式分别标记 |
| ATK-3~7（Token/格式/存在性） | 防护生效 → PASS | 同左 | PASS |
| ATK-8（Token 泄露直连） | **仍可操作 u_demo → REPRO** | REPRO | **任何模式都不得标 PASS（R12）** |
| ATK-9/10（legacy_*/任意 uid） | forbidden → PASS | 不适用 | PASS |
| ATK-11（u_demo 正常读写） | 200 → PASS | PASS | PASS |

> 纪律：ATK-1/2 只能在 p4_demo 下记 PASS（标注"P4 白名单生效，非用户认证"）；**ATK-8 永不 PASS**；报告必须写明部署模式。

## 5. L5 前端业务验收清单（手动，S6）

1. .env 设 EAT_SERVER_BASE_URL=http://127.0.0.1:8080 + Token → start-all 启动
