## 总量预估

- 新增 C++ 文件 ~20 个（全部 server/http/）、SQL 2 个、Python 测试 4 个、文档增补 3 处
- 既有文件改动：CMakeLists.txt（+1 目标）、.env.example（+5 行）——**server/ 既有源码零改动**
- 总工期约 6.5-7.5 人日（含调试缓冲）

## 风险与缓解

| 风险 | 缓解 |
|---|---|
| httplib 多线程 + MySQLPool 死锁 | S1 起跑 L3.32 并发压测；RAII 归还连接；池大小=线程数 |
| heredoc/转义导致的 SQL 编写错误（P7 教训） | SQL 全部走文件不走命令行管道；迁移前 mysqldump 备份 |
| Agent 侧行为与预期偏差 | L4 以 ServiceClient 类为黑盒断言（不 mock Agent 内部）；差异逐条记录为 G-x |
| 时区错位 | S1 单测锁定本地时区日期（today 断言） |
| 学长 main 并行演进 | 每阶段开始前 fetch main + rebase 检查 chatroom-backend 零冲突（main 侧零交集已验证） |
